Ağ Güvenliği dersi kapsamında geliştirilen, sosyal mühendislik ve oltalama (phishing) farkındalığını göstermeye yönelik eğitim amaçlı web simülasyonları.

## Proje Hakkında

Bu repo, kullanıcıların oltalama saldırılarına karşı nasıl kandırılabileceğini göstermek amacıyla hazırlanmış, tamamen eğitim/farkındalık odaklı simülasyon sayfaları içerir. **Herhangi bir gerçek veri toplamaz veya üçüncü bir sisteme veri göndermez.**

| Klasör | Açıklama |
|---|---|
| `WiFi-Captive-Portal-Simulasyon-GENIS/` | Sahte bir "ücretsiz Wi-Fi" giriş sayfası simülasyonu |
| `hediye-cekilisi/` | "500 TL hediye çekilişi" temalı sahte kampanya sayfası simülasyonu |
| `quiz_game_web/` | "Renkli kart quiz çekilişi" temalı simülasyon |

## Kullanılan Teknolojiler

- HTML, CSS, JavaScript

## Kurulum ve Çalıştırma

Her klasördeki `index.html` dosyasını tarayıcıda açmanız yeterlidir:

```bash
git clone https://github.com/mrvbyrm/Ag_Guvenligi.git
cd Ag_Guvenligi/hediye-cekilisi
# index.html dosyasını bir tarayıcıda açın
```
